# ANSUR II data

Place the two public ANSUR II CSV files in this directory:

- ANSUR II MALE Public.csv
- ANSUR II FEMALE Public.csv

Run:

    python scripts/download_ansur.py

The public ANSUR II working databases contain 4,082 male and 1,986 female participants and 93 directly measured anthropometric dimensions.

The raw CSV files are intentionally not committed to this repository. The project downloads them when needed so the Git history stays lightweight.

Official documentation:
- U.S. Army Defense Centers for Public Health
- The OPEN Design Lab, Penn State
