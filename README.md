# BMEdesignNaeemi

## طراحی هوشمند ارتز مچ و دست با Python

این پروژه یک نمونه آموزشی برای طراحی پارامتریک ارتز مچ و دست است. اندازه‌های نمونه در `examples/design_example.py` تعریف شده‌اند؛ محیط مچ به‌جای مقدار ثابت، با Random Forest و داده‌های آنتروپومتریک ANSUR II تخمین زده می‌شود و سپس به سازنده هندسه ارتز داده می‌شود.

> **این پروژه آموزشی/پژوهشی است و برای ساخت یا تجویز وسیله پزشکی واقعی طراحی نشده است.**

### جریان اجرا

**Measurements → ML wrist-circumference estimate → Parametric orthosis → 3D mesh → STL and metrics**

### نصب و اجرا

```bash
pip install -r requirements.txt
python examples/design_example.py
```

فایل‌های ANSUR II باید در پوشه `data/` باشند:
- `ANSUR II FEMALE Public.csv`
- `ANSUR II MALE Public.csv`

کد از هر فایل معتبر و غیرخالی استفاده می‌کند. در نسخه فعلی مخزن فایل مردان خالی است؛ بنابراین مدل فعلاً فقط با داده‌های زنان آموزش می‌بیند. برای تعمیم به جمعیت‌های دیگر، فایل معتبر مردان و سپس داده‌های مستقل از جمعیت هدف باید اضافه و ارزیابی شوند.

### نقش ML

مدل سه اندازه‌ی موجود در ورودی پروژه را می‌گیرد: طول دست، عرض دست و محیط ساعد. خروجی آن محیط مچ پیش‌بینی‌شده بر حسب میلی‌متر است. این خروجی جایگزین مقدار ثابت محیط مچ در مثال شده و مستقیماً برای ساخت مدل سه‌بعدی استفاده می‌شود. MAE و RMSE روی یک بخش آزمون تصادفی از همان داده‌ها چاپ می‌شوند تا خطای تخمین دیده شود.

### محدودیت‌ها

ANSUR II شامل بزرگسالان نظامی ایالات متحده است و نماینده همه جمعیت‌ها نیست. ارزیابی holdout تصادفی، اعتبار بالینی یا دقت روی جمعیت‌های دیگر را اثبات نمی‌کند. پیش‌بینی باید با اندازه‌گیری واقعی روی نمونه‌های مستقل اعتبارسنجی شود؛ برای ارتز قابل استفاده پزشکی، اندازه‌گیری و بررسی متخصص ضروری است.
