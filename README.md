# BMEdesignNaeemi

## طراحی هوشمند ارتز مچ و دست با Python

این پروژه یک نمونه دانشگاهی برای طراحی پارامتریک و محاسباتی یک ارتز مچ و دست است. کاربر چند اندازه آنتروپومتریک را وارد می‌کند و نرم‌افزار بر اساس آن‌ها ابعاد ارتز را محاسبه کرده، یک مدل سه‌بعدی ساده و قابل تنظیم تولید می‌کند و شاخص‌هایی مانند حجم، جرم تخمینی و نسبت بازشدگی را گزارش می‌دهد.

> **هدف پروژه آموزشی/پژوهشی است و برای ساخت یا تجویز وسیله پزشکی واقعی طراحی نشده است.**

### ایده اصلی

**Anthropometry → Parametric Design → 3D Mesh → STL → Metrics → Visualization**

### قابلیت‌ها

- دریافت و اعتبارسنجی اندازه‌های مچ، دست و ساعد
- طراحی پارامتریک پوسته ارتز
- سه الگوی طراحی: solid، perforated و hex
- محاسبه حجم، سطح، جرم تخمینی و open-area
- نمایش سه‌بعدی مدل
- خروجی STL
- نمونه ساده ML برای تخمین یک اندازه مفقود
- تست‌های پایه و مثال اجرایی

### نصب

```bash
pip install -r requirements.txt
```

### اجرا

```bash
python examples/design_example.py
```

خروجی STL در پوشه `output/` ساخته می‌شود.

### ساختار

- `src/bmedesign/anthropometry.py` — داده‌های آنتروپومتریک و اعتبارسنجی
- `src/bmedesign/geometry.py` — تولید مش پارامتریک
- `src/bmedesign/orthosis.py` — سازنده ارتز
- `src/bmedesign/metrics.py` — محاسبات مهندسی
- `src/bmedesign/visualization.py` — نمایش مدل
- `src/bmedesign/ml.py` — بخش یادگیری ماشین
- `docs/methodology.md` — روش‌شناسی
- `docs/presentation.md` — سناریوی ارائه

### نکته درباره ML

مدل ML در این پروژه صرفاً یک نمونه computational design است. برای کاربرد پژوهشی واقعی، باید از داده آنتروپومتریک معتبر، ارزیابی مستقل و جمعیت هدف مناسب استفاده شود. داده نمونه موجود در این مخزن مصنوعی/آموزشی است و نباید به‌عنوان داده بالینی تلقی شود.
